# 个人交易体系总结

> 本文为个人投资交易体系的可执行规则总结，不构成荐股；历史案例不代表未来收益。

## 一、底层认知

1. 股市赚的是**资金流和趋势的钱**，不是靠“买企业长期持有”就一定能赚钱。
2. 只参与**资金已经认可的上升趋势**。趋势启动后跟进，趋势结束前退出。
3. 禁止给一路下跌的标的“雪中送炭”。上涨趋势里的回踩要敢接，下跌趋势里的反弹不要抢。
4. 横盘阶段不猜方向，等放量突破并确认上行后再参与。
5. 原则是“强更强”，主动避开无人关注、长期下跌、走势凌乱的票。

## 二、趋势识别

- 上升趋势：短期均线持续向上；小波段低点逐步抬高，高点也逐步抬高。
- 下跌趋势：低点、高点持续下移，均线向下。
- 横盘：没有明确高低点抬高或下降，等突破确认。

参与方式：

- 上升趋势：回调参与。
- 下跌趋势：不参与。
- 横盘：等突破确认上行。

## 三、MA15 执行规则

MA15 是**执行工具，不是选股工具**。先看大势、板块和标的方向，再用 MA15 做进出场。

- 股价站上 MA15：买入。
- 股价跌破 MA15：卖出。
- 趋势明确时，贴着 MA15 可能反复穿越，产生摩擦成本，但主升段收益应覆盖这些成本。
- 下跌趋势中严格按 MA15 操作，主要目标是避免深套；不要指望靠 MA15 抄底赚钱。
- 不能只因为均线金叉、死叉或某只股票站上均线就选股。

## 四、涨停启动选股公式

适合“连板启动、随后沿均线走趋势、再加速”的蛇形走势标的。原文公式如下，参数 `F`、`R` 是可调参数：

```text
ZT:=C/REF(C,1)>1.095 AND C=H;
FZT:=BARSSINCEN(ZT,R);
AA:=MA(CLOSE,5);
BB:=MA(CLOSE,10);
CC:=MA(CLOSE,30);
DD:=MA(CLOSE,60);
T1:=AA>BB AND BB>CC AND CC>DD;
COUNT(T1,(FZT-5))/(FZT-5)>=0.7
AND BETWEEN(FZT,F,R)
AND BARSCOUNT(CLOSE)>=R+1
AND COUNT(CLOSE<ZT,FZT)/FZT<=0.2
AND C>ZT;
```

使用规则：

1. 条件放宽，先保证不漏机会。
2. 程序选出后必须人工筛选。
3. 剔除连续涨停、走势凌乱、成交不活跃的标的。
4. 关注回落后仍站稳均线、趋势结构完整、准备二次加速的标的。

## 五、买点规则

可尝试买入的形态：

- 分时均线向上。
- 分时线明显运行在分时均线上方。
- 价格贴近分时均线附近。
- 量能健康。
- 同时结合板块节奏、个股处于相对低位、板块内批次切换。

不能买入的形态：

- 分时均线下行。
- 分时线持续被分时均线压制。
- 无量上涨，或明显高位放量滞涨。

## 六、卖点规则

出现以下情况，按减仓处理：

1. 分时线每个波动的高点都被分时均线压制。
2. 分时线略微突破均线后重新跌破，并继续创新低。
3. 股价跌破 MA15，且 MA15 开始拐头向下。
4. 板块龙头转弱，同板块跟风股大面积冲高回落。

## 七、相对强弱抄底

不是无脑抄指数底部，而是找**强于指数的强势股提前见底**：

- 指数仍创新低。
- 强势股的波段低点开始抬高，并且比指数提前 1 到 2 个波段见底。
- 比较点：强势股第 3 个低点高于第 1 个低点；同一阶段指数第 3 个低点仍低于第 1 个低点。
- 这种“个股低点抬高、指数低点创新低”的背离，是相对强势股的重要底信号。

## 八、应用到当前持仓的参考顺序

1. 先判断指数和大势：大盘方向不明时不重仓。
2. 再判断板块：只看资金持续流入、趋势向上的方向。
3. 再判断标的：用涨停启动公式和相对强弱筛出候选。
4. 再用 MA15 和分时均线找买卖点。
5. 不上涨趋势的标的，只做反弹减仓或防守，不做摊平补仓。

当前持仓中的直接适用点：

- 恒生互联网、卫星 ETF：趋势仍弱时，按反弹减仓，不沿下跌趋势抄底。
- 三峡能源：横盘品种，等突破或明确趋势再决定加减仓。
- 中欧红利：接近目标时优先落袋，不因短期强势无脑追高。
- 永赢高端装备：军工反弹必须结合板块资金和 MA15 确认，不能只凭单日上涨就补仓。
