# 持仓说明（示例）

> 本项目为投资顾问工具。本文以示例说明分析方式，

## 当前状态

- 主模型：DeepSeek 文字模型，图片需走 DeepSeek 视觉、本地 Ollama 或 OCR。
- 项目定位：**投资顾问**。不实时盯盘、不自动交易；用户需要时提问，股神按需给出参考分析和未来走势预判。
- 用户目标：让股票和场外基金在尽量短的时间内达到 5% 以上收益，系统只提醒和参考，不自动交易。

## 使用方式

取消实时盯盘（60 秒采集、邮件告警、看板均已停止），改为**按需咨询**：

1. 用户提问某只股票/基金/持仓 → 股神按需分析。
2. 分析时结合：实时行情 + 技术面 + 消息面（利空/利好）+ 市场情绪 + 媒体/博主看法 + 大师框架 + TradingAgents-CN 多智能体分析。
3. 输出：明确动作 + 价格区间 + 防守位 + 改判条件 + 主要风险 + 未来走势预判。

## 分析工具链（按需使用）

1. 30 多位投资大师 perspective skill（巴菲特、格雷厄姆、林奇、佛莱斯等）。
2. `vibe-trading`（量化回测/因子，独立环境）。
3. 趋势交易体系（`docs/交易体系.md`）。
4. **TradingAgents-CN 多智能体分析**：`monitor/ta_bridge.py` 调用多角色（分析师/研究员/交易员/风控）分析，输出决策建议。手动运行：
   `TradingAgents-CN\.venv\Scripts\python.exe -m monitor.ta_bridge --code 600905 --name 三峡能源`
   （约耗 2-5 分钟 + DeepSeek 余额 1-3 元，按需触发，不频繁跑。）
5. 自进化记录：`reports/memory/`（预测账本、教训、概率校准）。

## 数据获取方式

- 行情：新浪、东方财富、AkShare 免费源（按需拉取，不再 60 秒轮询）。
- 场外基金净值：基金公司 T+1 晚间公布，盘中只有估值。
- 新闻/情绪：东方财富快讯、股吧帖子。

## 决策流程

1. 先读 `AGENTS.md`、`docs/交易体系.md`、`docs/持仓说明.md`、`reports/latest.json`（或按需拉行情）。
2. 六项证据：历史规律 + 实时消息面 + 技术面 + 盘面 + 市场情绪 + 媒体/博主看法。
3. 需要更专业的多角色视角时，跑 TradingAgents-CN 多智能体分析。
4. 交叉判断后给唯一结论 + 走势预判。

## 重要边界

- 不自动下单，不读取券商交易接口。
- 不在公开文件保存 API Key、邮箱授权码等敏感信息。
- 场外基金正式净值以基金公司晚间公布为准，盘中估值只是预测。
- 所有历史案例和模型概率都不代表保证收益。
