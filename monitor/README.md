# 分析模块

本项目核心分析代码位于 `monitor/`，负责行情抓取、技术指标计算、预测与自进化。

## 预测引擎

上涨概率由五个分量加权合成：

1. 技术模型：基于 L2 正则化逻辑回归，结合 MA、RSI、MACD、量比、波动率等因子，对最近 90 个交易日滚动训练，预测 T+1 方向。
2. 大师框架：按持仓风格（价值/成长/防守）适配投资大师视角，对模型概率做小幅修正。
3. 舆情情绪：用东方财富快讯做关键词情绪评分，A 股另接股吧热门帖子做散户情绪评分。
4. 趋势规则：按 `docs/交易体系.md` 的趋势判断（下跌不补仓、横盘等突破、上升回调参与）量化修正。
5. 多智能体分析：可选调用 TradingAgents-CN 做多角色交叉验证，见 `monitor/ta_bridge.py`。

## 自进化

- 预测账本：`reports/memory/predictions.jsonl`
- 概率校准：`reports/memory/profiles.json`
- 教训库：`reports/memory/lessons.jsonl`

## 数据来源

- 行情：新浪、东方财富、AkShare 免费源
- 场外基金净值：基金公司 T+1 晚间公布
